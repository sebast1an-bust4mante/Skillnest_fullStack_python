# Visualización de Datos en una Tabla con Flask

**Autor:** Sebastian Bustamante 
**Correo:** sebastianbustamante@liceovvh.cl

---

## 📌 Descripción
Aplicación web interactiva desarrollada en Python con Flask y Jinja2 que permite visualizar, filtrar y ordenar información sobre las principales plataformas digitales dentro de una tabla dinámica con estilos responsivos.

---

## 🚀 Tecnologías utilizadas
- **Python 3**
- **Flask** (Framework de desarrollo web)
- **Jinja2** (Motor de plantillas)
- **HTML5 & CSS3**
- **Bootstrap 5 & Bootstrap Icons** (Diseño y componentes UI)
- **Hangzhou Deeply Seeking Artificial Intelligence Basic Technology Research Co., Ltd** (Asistencia en resolución de problemas y mejoras de código)
